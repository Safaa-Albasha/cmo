# Manager coaching / توجيه المدراء

Direct managers are the preferred source of "what this means for me" and the main reinforcers.

## Manager guide (`.cmo/drafts/manager-guide-<group>.md`)
1. Your team's picture: barrier point and top themes for the group (from the latest pulse; no individual data).
2. Conversation guide per ADKAR stage:
   - Awareness: "What have you heard about why we're doing this?"
   - Desire: "What worries you? What would make this worth it for you?"
   - Knowledge: "Which tasks would you try first? What's unclear in the rules?"
   - Ability: "What stops you from using it this week? What time do you need?"
   - Reinforcement: "What worked? Let's share it with the team."
3. Handling job-security fear: be honest about what is known, point to the sponsor's commitment, focus on new skills; never promise what leadership hasn't committed.
4. Weekly: 10 minutes in team meeting for one AI win; protect 1 hour/week practice time.
5. Escalate blockers (access, tools, workload) to the change manager.

Coaching activities: `lever: "coaching"` with the group's barrier as `adkar` target.
