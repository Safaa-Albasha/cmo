# cmo: مكتب إدارة التغيير لتبنّي الذكاء الاصطناعي

[English](README.md) · [دليل التنزيل والتركيب](INSTALL.ar.md)

plugin لـ Claude Code تساعد مدير التغيير على **تخطيط تغيير تبنّي الذكاء الاصطناعي وتنفيذه وإثبات أثره**، سواء كانت الأداة Microsoft 365 Copilot أو Claude أو ChatGPT Enterprise أو Gemini.

تجمع بين ثلاثة أطر: مراحل Prosci الثلاث، وخطوات Kotter الثماني، ونموذج ADKAR. وتقيس ثلاثة مستويات قبل التغيير وبعده:

1. **الأشخاص:** درجات ADKAR، ونقاط العائق، والمشاعر. المصدر استبيانات Google Forms أو Microsoft Forms.
2. **التبنّي:** الاستخدام الفعلي من تقارير لوحات الإدارة: الاستخدام النشط، والتفعيل، والتكرار، والاستمرارية.
3. **الأثر على العمل:** وقت العمليات قبل وبعد، والساعات والمبالغ الموفّرة، والعائد على الاستثمار، وفترة الاسترداد، مع إثبات إحصائي.

**مبادئها:**
- **العربية والإنجليزية في كل شيء، والعملة يحددها مدير التغيير بحرية.**
- **لا أرقام مخمّنة:** Claude يصنّف التعليقات ويكتب التحليل، ومحرّك حسابات مستقل يحسب كل رقم.
- **الخصوصية في الكود نفسه:**
  - الأسماء والإيميلات تُستخدم فقط لإنشاء رموز مشفّرة، ثم تُحذف.
  - التعليقات تُنظَّف من الإيميلات والهواتف والروابط.
  - المجموعات التي فيها أقل من 5 أشخاص لا تُعرض نتائجها أبدًا.
  - حارس يمنع أي وصول لملف التشفير.
  - **ورقة وعد الخصوصية:** صفحة واحدة بالعربي والإنجليزي للموظفين ولجنة العاملين، تُولَّد من إعداداتك الفعلية، وملخصها يظهر في بداية كل استبيان.
- **القرار لك:** الوكلاء يقترحون، ولا تتغير الخطة أو المجموعات أو الرعاة أو العمليات أو سجل المقاومة إلا بموافقتك، ويُسجَّل كل قرار.
- **تقرير تفاعلي:** ملف واحد يعمل بدون إنترنت، يصلح لوحةً وعرضَ شرائح.

> تحتاج Node.js 18 أو أحدث.
>
> Prosci® وADKAR® علامتان تجاريتان لشركة Prosci, Inc.، وإطار Kotter ذو الخطوات الثماني محفوظ الحقوق لشركة Kotter, Inc. هذه الإضافة غير تابعة لأي منهما، ومحتواها أصلي ومستوحى من هذه الأطر.

## التثبيت

```bash
claude plugin marketplace add Safaa-Albasha/cmo
claude plugin install cmo@cmo
```

أعد تشغيل Claude Code، وافتح مجلدًا لبرنامج التغيير، ثم شغّل `/cmo:setup`. الدليل الكامل خطوة بخطوة في [INSTALL.ar.md](INSTALL.ar.md).

## الرحلة المعتادة

1. **`/cmo:new`:** حدّد التغيير، ونوعه (قالب تبنّي الذكاء الاصطناعي)، واللغة، والعملة، والتواريخ.
2. **`/cmo:assess`:** المجموعات المتأثرة، ودرجة الأثر، والجاهزية، والمخاطر.
3. **`/cmo:survey`:** الاستبيان **الأساسي**، وهو ملف Quick Import لـ Microsoft Forms أو سكربت لـ Google Forms.
4. **`/cmo:value`:** سجّل 3 إلى 7 عمليات رئيسية مع وقتها الحالي، وولّد نموذج قياس الوقت الفعلي.
5. **`/cmo:plan`:** خطة تجمع Prosci وKotter وADKAR، ثم اعتمدها في `/cmo:approvals`.
6. **نفّذ التغيير، ثم:**
   - **كل 6 إلى 8 أسابيع:** استبيان متابعة عبر `/cmo:survey`، ثم استيراد الإجابات عبر `/cmo:import`، ثم التحليل عبر `/cmo:pulse`.
   - **كل شهر:** استورد تقارير الاستخدام عبر `/cmo:import`.
7. **في أي وقت:** `/cmo:status` لعرض الحالة، و`/cmo:report` لتجهيز تقرير اللجنة التوجيهية.

**جرّب أولًا على المثال:** انسخ مجلد `examples/ai-adoption`، وافتحه في Claude Code، ثم شغّل `/cmo:status`. ويوجد تقرير جاهز للمعاينة في `examples/sample-report-ai-adoption.html`.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `/cmo:setup` | فحص الجاهزية (Node، والمشروع، وملف التشفير)، وطرق الربط |
| `/cmo:new` | إنشاء مشروع التغيير (`.cmo/`) |
| `/cmo:assess` | الأثر، والجاهزية، ومخاطر الجانب البشري |
| `/cmo:plan` | تغطية الخطة للمراحل وخطوات Kotter وعناصر ADKAR، والأنشطة المتأخرة، و**فجوات العوائق**: نقطة عائق لا يعالجها أي نشاط مفتوح |
| `/cmo:survey` | جولات الاستبيان الأساسية والمتابعة، بملفات جاهزة لـ Microsoft Forms وGoogle Forms، وورقة وعد الخصوصية |
| `/cmo:import` | إجابات الاستبيان، وتقارير الاستخدام مع ملف أقسام الموظفين، وعينات قياس الوقت |
| `/cmo:pulse` | تصنيف التعليقات، ثم مراجعة المدير، ثم تحليل الجولة والإجراءات |
| `/cmo:value` | العمليات، وقبل وبعد، والعائد على الاستثمار، والاسترداد، والإثبات الإحصائي |
| `/cmo:resistance` | إشارات المقاومة وسجلها |
| `/cmo:status` | الجاهزية، وADKAR، والمشاعر، والتبنّي، والأثر، والخطة |
| `/cmo:report` | التقرير التفاعلي والعرض |
| `/cmo:approvals` | البتّ في المقترحات، مع سجل القرارات |

## كيف تُحسب المؤشرات

| المؤشر | طريقة الحساب |
|---|---|
| عنصر ADKAR | متوسط سؤالَيه (من 1 إلى 5) لكل مجموعة |
| نقطة العائق | أول عنصر درجته أقل من 3، بترتيب: الوعي، ثم الرغبة، ثم المعرفة، ثم القدرة، ثم التعزيز |
| صافي المشاعر | نسبة التعليقات الإيجابية ناقص نسبة السلبية. التصنيفات منخفضة الثقة يراجعها المدير قبل احتسابها |
| الاستخدام النشط | عدد النشطين أسبوعيًا ÷ عدد المرخّص لهم |
| الجاهزية | ADKAR بوزن 50%، والمشاعر 20%، والاستخدام 30%. النتيجة من 0 إلى 100: 🟢 من 70 فأكثر، و🟡 من 50 فأكثر |
| الوقت الموفّر | الفرق في الدقائق بين قبل وبعد (🟢 مقاس أو 🟡 تقدير) × عدد مرات التنفيذ الشهرية |
| الإثبات | ✔ "مؤكد" عند وجود 5 عينات على الأقل في كل جهة، وقيمة p أقل من 0.05 |
| العائد على الاستثمار | (القيمة ناقص التكلفة الشهرية) ÷ التكلفة الشهرية |

**ملاحظتان:** الوقت الموفّر طاقة متاحة، ولا يصبح توفيرًا ماليًا إلا إذا أُعيد توظيفه. والعمليات التي صارت أبطأ تُعرض كما هي، ولا تُخفى.

## Claude Desktop (Cowork)

المهارات والأوامر والوكلاء والحارس مدعومة في Cowork. لكن محرّك الحسابات يحتاج Node.js في البيئة التي يعمل فيها Claude. لذلك شغّل `/cmo:setup` في Cowork:
- **إذا كان Node متوفرًا:** كل شيء يعمل.
- **إذا لم يكن متوفرًا:** استخدم Claude Code للأرقام، وأخبرنا بالنتيجة.
